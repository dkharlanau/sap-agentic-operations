# SAP Agentic Operations — Practical Toolkit 0.4.0-alpha.2

Alpha 2 extends the usable local-first toolkit with an evidence-safe bridge from public research and a complete synthetic customer-governance assurance path.

## Highlights

- Validate Signal to Insight v1 evidence packets with schema, digest, publication-state, and privacy boundaries.
- Render Markdown-safe human review cards without treating research as operational truth.
- Run the synthetic Customer Governance to Order-to-Cash reference assurance set across architecture, requirements, controls, incident evidence, benchmark cases, and dynamic variants.
- Preserve stable cross-repository artifact references and business-event idempotency checks.
- Use the same zero-runtime-dependency `sao` package and practical incident/reconciliation workflows introduced in Alpha 1.

## Verify

Run the [golden quickstart](GOLDEN-QUICKSTART-0.4.0-alpha.2.md). Release assets include a reproducible wheel, a deterministic `git archive` source snapshot, and checksums built from the proven tag.

## Compatibility and non-goals

- Practical Evidence Pack and CLI behavior remain Alpha-1 compatible; this is still a prerelease.
- `sao research` accepts external review context only. It cannot authorize, execute, or prove a production incident.
- The reference assurance set is synthetic and does not establish production suitability or SAP certification.
- SAO-Bench remains separately versioned as `0.3-dev`; no benchmark freeze is implied.
- No live SAP connector, production write automation, or package-registry publication is included.
